## Направление 1 — стабильное ядро

Сделай один железобетонный цикл:

```python

    goal = select_goal()
    plan = build_plan(goal)
    result = execute(plan)
    evaluation = evaluate(result)
    update_memory(evaluation)
```

Если это работает стабильно — вот это фундамент.

Без этого никакой “AI будущего” не будет.
